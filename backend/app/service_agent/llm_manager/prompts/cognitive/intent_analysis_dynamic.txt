## 분석 원칙

### 부동산 관련 질문 판단 기준
단순 키워드가 아닌 **맥락과 의도**를 파악하세요.

**부동산 관련 질문의 특징**:
- 주거 공간 관련: 집, 방, 거주, 살 곳, 자취, 이사
- 거래/계약 관련: 매매, 임대, 전세, 월세, 계약, 분양
- 법률/권리 관련: 임대차법, 계약서, 권리, 의무, 갱신, 해지
- 금융/대출 관련: 주택담보대출, 전세자금대출, LTV, DTI
- 시세/가격 관련: 부동산 가격, 시세, 시장 동향, 매매가, 전세가

**IRRELEVANT (무관) 판단 기준**:
1. 명백히 다른 분야: 주식, 코인, 여행, 음식, 날씨, 일반상식
2. 인사/감탄사 (10자 이하): "안녕", "ㅋㅋ", "와", "테스트", "123"
3. 의미 없는 입력: "...", "???", "asdf"

**중요**: 키워드가 없어도 맥락상 부동산과 관련이 있으면 분석을 진행하세요.

## 분석 단계

### 1단계: 질문 유형 파악
- 정보 확인형: "~이 뭐야?", "~알려줘" → 검색만으로 충분
- 평가/판단형: "괜찮아?", "문제있어?" → 검색 + 분석 필요
- 해결책 요청형: "어떻게?", "방법?" → 검색 + 분석 + 제안 필요

### 2단계: 복잡도 평가
- **저**: 단일 개념/사실 확인
- **중**: 특정 상황 + 판단
- **고**: 복잡한 상황 + 여러 조건 + 해결책

### 3단계: Intent 결정
위에 제공된 Intent 정의의 **description**과 **examples**를 참고하여
가장 적합한 Intent를 선택하세요.

## 분석 지침

1. **맥락 이해**: 위 대화 기록을 반드시 참고하여 현재 질문의 맥락을 이해하세요
2. **지시어 처리**: "그럼", "그거", "그건", "아까", "그때", "방금", "위에서" 등의 지시어가 있으면 이전 대화에서 언급된 내용을 찾으세요
3. **연속성 판단**: 이전 대화와 연결되는 질문이면 부동산 관련 질문으로 처리하세요
4. **Description 기반**: Intent 정의의 description을 우선적으로 참고하고, examples는 보조 자료로 활용하세요

**데이터 재사용 판단** (매우 엄격하게 판단):
다음 조건을 **모두 만족**할 때만 **"reuse_previous_data": true**로 설정하세요:
1. **명시적 지시어 존재**: "방금", "위", "그", "이전", "아까", "그 데이터로", "그 정보로", "그걸로", "거기에", "그 매물", "그 아파트" 등
2. **새로운 검색 불필요**: 추가 데이터 수집이나 조회가 필요하지 않음
3. **기존 데이터로 충분**: 이전 대화의 검색 결과만으로 답변 가능

**reuse_previous_data: false로 설정해야 하는 경우**:
- ❌ **새로운 주소/건물/지역을 명시한 경우** → 새로운 검색 필요
- ❌ **새로운 검색 요청** (예: "○○ 조회해줘", "△△ 정보 뽑아줘") → 새로운 데이터 수집 필요
- ❌ **새로운 조건/필터 추가** → 새로운 검색 필요
- ❌ **다른 유형의 정보 요청** → 다른 도구/데이터 소스 필요

## 응답 형식 (JSON)

반드시 다음 JSON 형식으로 응답하세요:

```json
{
    "intent": "INTENT_NAME",
    "confidence": 0.9,
    "keywords": ["keyword1", "keyword2"],
    "entities": {
        "location": "강남구",
        "price": "5억",
        "contract_type": "전세"
    },
    "reuse_previous_data": false,
    "reasoning": "1단계: 질문 유형 분석 → 2단계: 복잡도 평가 → 3단계: Intent 정의의 description 기반 판단"
}
```

**필드 설명**:
- `intent`: Intent 이름 (위의 intent_definitions에서 선택, 대문자_언더스코어 형식)
- `confidence`: 0.0~1.0 (0.8 이상 매우 확실, 0.5 미만 불확실)
- `keywords`: 질문에서 추출된 주요 키워드
- `entities`: 위치, 가격, 계약 타입 등 추출된 엔티티
- `reuse_previous_data`: 이전 검색 결과 재사용 여부 (매우 보수적으로 판단)
- `reasoning`: **반드시 3단계 분석 과정 포함** (질문 유형 → 복잡도 → Intent 결정)

---

**중요**:
- Intent 정의의 **description**을 우선적으로 참고하세요
- **examples**는 참고용이며, description이 최종 판단 기준입니다
- chat_history가 비어있지 않으면 반드시 맥락을 고려하세요
